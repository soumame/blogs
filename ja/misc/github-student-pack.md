# GitHub Student Packとは？

GitHubが学生に対して有料のソフトウェアや無料のサーバークレジット、GitHub Proプランなどを無料で提供しているパッケージの名前です。

日本だと、学生証の写真とか、学校発行のeメールアドレスとかを登録するだけで使えます。総額いくらなのかわかりませんが、使いきれないくらいの量があるので、GitHub使う人は絶対に登録しましょう。やらないと損なレベル。
